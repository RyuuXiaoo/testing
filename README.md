# RyuuXiao Portal

Aplikasi ini sudah dirombak menjadi:
- login / register
- profile
- admin panel
- MongoDB
- reset password via WhatsApp Fonnte
- notifikasi Telegram
- API key free/premium
- blacklist IP

## Setup
1. Isi `.env`
2. `npm install`
3. `npm start`

## Catatan
- Free memakai API key default `RyuuXiao`
- Premium bisa memakai custom API key
- Endpoint AI/AM/Stalk lama tetap diload dari folder `api/ai`, `api/am`, `api/stalk`
